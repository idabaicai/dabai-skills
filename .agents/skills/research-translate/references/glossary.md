## 评级体系

不同投行的评级体系不同，但都分"看多 / 中性 / 看空"三档。译成中文时**对应到该体系的规范档位措辞**，
不要混用。评级是研报最先被读者抓取的信息，译错一个字就串档。

**Goldman Sachs / 多数券商（Buy–Neutral–Sell 体系）**
- Buy → 买入
- Neutral → 中性
- Sell → 卖出

**Morgan Stanley / J.P. Morgan / 多数体系（Overweight 体系）**
- Overweight (OW) → 增持
- Equal-weight (EW) / In-Line → 与大盘持平 / 中性
- Underweight (UW) → 减持

**Credit Suisse / RBC 等（Outperform 体系）**
- Outperform (OP) → 跑赢大盘 / 跑赢行业
- Market Perform / Sector Perform → 与大盘持平 / 中性
- Underperform (UP) → 跑输大盘

**评级动作**
- Upgrade → 上调评级；Downgrade → 下调评级
- Reiterate / Maintain → 维持（评级）
- Initiate coverage / Initiating at Buy → 首次覆盖，给予买入评级
- Resume coverage → 恢复覆盖
- Under review → 评级审阅中

**目标价相关**
- Price Target (PT) / Target Price → 目标价
- Raise/Cut PT to → 上调/下调目标价至
- Upside / Downside → 上行空间 / 下行空间
- 12-month price target → 12 个月目标价

## 估值方法

- DCF (Discounted Cash Flow) → 现金流折现法
- SOTP (Sum-of-the-Parts) → 分部估值法
- P/E (Price-to-Earnings) → 市盈率
- Forward P/E → 前瞻市盈率；Trailing P/E → 静态/滚动市盈率
- PEG → 市盈率相对盈利增长比率（PEG）
- P/B (Price-to-Book) → 市净率
- P/S → 市销率
- EV/EBITDA → 企业价值倍数（EV/EBITDA）
- EV (Enterprise Value) → 企业价值
- Dividend Yield → 股息率
- WACC → 加权平均资本成本（WACC）
- Terminal growth rate → 永续增长率
- Discount rate → 折现率
- Target multiple → 目标（估值）倍数
- Re-rate / De-rate → 估值重估（抬升）/ 估值回落
- Rerating → 估值中枢上移

## 财务与会计术语

- Revenue / Top line → 营业收入 / 收入
- Net income / Earnings / Bottom line → 净利润
- EPS (Earnings Per Share) → 每股收益（EPS）
- EBIT → 息税前利润（EBIT）
- EBITDA → 息税折旧摊销前利润（EBITDA）
- Gross margin / Operating margin / Net margin → 毛利率 / 营业利润率 / 净利率
- Free Cash Flow (FCF) → 自由现金流（FCF）
- Operating Cash Flow (OCF) → 经营性现金流
- CapEx (Capital Expenditure) → 资本开支
- OpEx → 运营支出
- COGS → 营业成本 / 销货成本
- SG&A → 销售、管理及行政费用（SG&A）
- R&D → 研发费用
- Guidance → （业绩）指引
- Consensus / Street estimates → 市场一致预期 / 卖方一致预期
- Backlog → 在手订单 / 积压订单
- Book-to-bill → 订单出货比
- Order book / Bookings → 订单量 / 新签订单
- Inventory / Destocking / Restocking → 库存 / 去库存 / 补库存
- ASP (Average Selling Price) → 平均售价
- Utilization rate → 产能利用率
- Take rate → 抽成率 / 变现率
- ARPU → 每用户平均收入（ARPU）
- Churn → 用户流失（率）
- ROE / ROIC / ROA → 净资产收益率 / 投入资本回报率 / 总资产收益率
- Net debt / Leverage → 净负债 / 杠杆率
- Payout ratio → 派息率
- Buyback / Share repurchase → 股票回购
- Dilution → 摊薄
- Working capital → 营运资本
- Impairment / Write-down → 减值 / 资产减记
- One-off / Non-recurring → 一次性 / 非经常性（损益）

## 数字、单位与时间

- bn (billion) → 十亿；换算成中文习惯用"亿"（$1.2bn = 12 亿美元）
- mn/mm (million) → 百万；换算（$850mn = 8.5 亿美元）
- k (thousand) → 千
- bps / bp → 基点（1 基点 = 0.01%）
- pp / ppt / pts → 个百分点
- YoY (year-over-year) → 同比
- QoQ (quarter-over-quarter) → 环比
- MoM (month-over-month) → 环比（月度）
- CAGR → 复合年增长率
- FY (fiscal year) → 财年（FY24 = 2024 财年，注意有的公司财年不跟自然年）
- CY (calendar year) → 自然年 / 日历年
- 1Q/2Q/3Q/4Q → 一/二/三/四季度（1Q25 = 2025 年一季度）
- H1 / H2 → 上半年 / 下半年
- LTM / TTM → 最近十二个月
- NTM → 未来十二个月
- vs. → 相较 / 对比
- flat → 持平；up/down → 上升/下降

**货币符号**：$ 不一定是美元——HK$（港元）、S$（新加坡元）、A$（澳元）、C$（加元）、
NT$（新台币）、Rmb/CNY（人民币）、€（欧元）、£（英镑）、¥（日元或人民币，看上下文）。
翻译时币种必须保留，别默认都是美元。

## 分析师行话

这些词常出现在观点段，带有"分寸"，照实翻、别加码减码：

- beat / miss → 超预期 / 不及预期
- in line (with expectations) → 符合预期
- guide up / guide down → 上调 / 下调指引
- pre-announce → 提前预告（业绩）
- print (a good quarter) → 交出（一份不错的季报）
- read-through → （对…的）连带启示 / 传导影响
- tailwind / headwind → 顺风（利好因素）/ 逆风（不利因素）
- de-risked → 风险已释放 / 利空出尽
- priced in → 已被（股价）计入 / 已反映在股价中
- overhang → （压制股价的）悬顶因素 / 不确定性压制
- structural / secular → 结构性的 / 长期趋势性的
- cyclical → 周期性的
- inflection (point) → 拐点
- runway → 增长空间 / 发展空间
- moat → 护城河
- conviction → 确信度 / 信心（high-conviction Buy = 高确信度买入）
- constructive → 偏正面 / 建设性看好
- cautious → 谨慎
- well-positioned → 处于有利地位 / 有望受益
- headroom → （增长/利润率的）提升空间

**限定词分寸**（务必区分强弱，不要译错档）：
- modest → 温和的（弱）
- meaningful / material → 可观的 / 实质性的（中强）
- significant / substantial → 显著的 / 大幅的（强）
- could / may / might → 可能（弱推测）
- likely → 很可能（较强）
- we expect / we forecast → 我们预计（中性预测）
- we believe → 我们认为
- we are confident → 我们有信心（强）

## 宏观与市场术语

- Fed (Federal Reserve) → 美联储
- rate cut / rate hike → 降息 / 加息
- basis points on rates → （利率）基点
- soft landing / hard landing → 软着陆 / 硬着陆
- inflation / CPI / PPI / core PCE → 通胀 / 消费者物价指数 / 生产者物价指数 / 核心 PCE 物价指数
- GDP growth → GDP 增速
- yield curve / inversion → 收益率曲线 / 倒挂
- risk-on / risk-off → 风险偏好上升 / 避险情绪升温
- multiple expansion / compression → 估值扩张 / 估值收缩
- rotation → 板块轮动
- overweight/underweight a sector → 超配 / 低配（某板块）
- long / short → 做多 / 做空
- FX / forex → 外汇
- hedge → 对冲
