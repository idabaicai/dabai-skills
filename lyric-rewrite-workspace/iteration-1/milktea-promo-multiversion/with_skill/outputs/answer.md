# 《小苹果》奶茶店开业宣传歌 · 两个版本备选

套用《小苹果》原旋律，每句字数与原词严格对齐（10 / 8 / 12 / 11），洗脑好记、开口能唱。

---

## 版本一：甜萌洗脑版（原曲：《小苹果》）

定位：贴着原词句式改，最大程度"借"原曲的洗脑感，主打珍珠奶茶的甜与可爱，适合店内循环播放、短视频卡点。

```
你是我的小呀小奶茶儿
喝你一口甜到心窝
满满的珍珠儿弹弹我的舌尖
开业全场半价喝 喝喝喝喝
```

亮点：
- "你是我的小呀小奶茶儿" 直接对位 "小苹果儿"，一开口观众就 get 到是改的哪首歌。
- 结尾把招牌的 "火火火火" 换成 "喝喝喝喝"，谐音呼应又点题（开业=半价喝），最抓耳的记忆点。

---

## 版本二：魔性叫卖版（原曲：《小苹果》）

定位：街边叫卖 / 促销风，强调"开业""第二杯半价""排队"等转化钩子，适合门口大喇叭、地推、直播间喊麦。

```
走过路过别错过小奶茶
第二杯只要半价多
新店今天开张全城最最划算
快来排队喝一杯 喝喝喝喝
```

亮点：
- 开句 "走过路过别错过" 是经典叫卖梗，路人秒懂、行动指令直接。
- 把优惠信息（半价、新店开张、最划算）全塞进旋律里，唱完一遍就是一条完整广告。
- 同样用 "喝喝喝喝" 收尾，和版本一保持统一的招牌钩子。
