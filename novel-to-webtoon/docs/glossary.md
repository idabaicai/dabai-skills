# 小说条漫改编术语表

| 术语 | 含义 |
| --- | --- |
| 改编包 | 供用户统一审阅的阶段性成果：章节拆分、角色设定、分镜脚本与绘图提示词。 |
| 条漫 | 为手机纵向滚动阅读设计的竖屏漫画（Webtoon）。 |
| 分镜脚本 | 对每个画格的剧情动作、台词、镜头、情绪与视觉重点的说明。 |
| 角色设定 | 用于维持角色在多集、多张图中一致性的身份、外观、服装与视觉特征档案。 |
| 绘图提示词 | 向图像生成工具说明单个画面内容、构图与风格的指令。 |
| 风格圣经 | 从用户要求和参考图提炼的、供全项目复用的视觉规范，包括画风、色彩、线条、角色外观与禁用项。 |
| 参考图 | 用户提供、用来指导角色外观、服装、构图或视觉风格的图片；应在使用时标明具体作用。 |
