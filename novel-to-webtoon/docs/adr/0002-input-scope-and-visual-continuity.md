# ADR-0002：限定首版输入，并以风格圣经维持视觉连续性

## 状态

已采纳（设计中）

## 决策

第一版仅接收用户直接粘贴的小说文本，或本地 Markdown/TXT 文件。每次运行由用户指定一个章节或一段连续剧情，而不是自动改编整本小说。

用户可以文字指定视觉方向或上传参考图。技能据此输出风格圣经，并让之后的分镜与图像生成沿用该圣经。

## 理由

纯文本输入能可靠地保留章节与段落语义，避免复杂文件解析干扰改编质量。较小的改编范围便于先检验节奏与画风。将用户参考转化为可复用的风格圣经，能避免跨画格或跨集漂移。

## 后果

- DOCX、EPUB、PDF 与网页导入留待后续版本。
- 提示用户明确圈定源文本范围。
- 生成图片前需建立并复用风格圣经。
