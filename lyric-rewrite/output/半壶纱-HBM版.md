### 工艺线（一句话主旨：一粒硅砂，层层堆叠，长成高带宽内存）

- **主歌**：硅片入炉 → DRAM 存储单元阵列 → 氧化镀膜 → 金属互连布线
- **副歌 A**：TSV 硅通孔深孔刻蚀 → 电镀铜填孔 → 晶圆减薄 → 长微凸点（microbump）
- **副歌 B（招牌段）**：晶圆层层对位 → 一层层 die 堆叠 → 热压键合（TC bonding） → 塑封 + 良率把关 → 接 GPU/算力，输出高带宽

### 字数与韵脚

- 全 30 句字数与原词逐句对齐（脚本核验 ✅）。
- 主歌 + 副歌 A 押 **a** 韵（华·麻·华·下 / 砂·洼·纱·芽），对应原词的 花·家·麻·下 / 华·发·纱·茶。
- 副歌 B 首句"晶圆"不入韵（对应原词"山水"），其余押 **ao** 韵（好·到·靠·高·了），对应原词 到·祷·草·老·了。

### 贴着原词改的"影子"

- 招牌句 `我便一步一莲花祈祷` → `我便一层一硅芯拥抱`：用"一层一硅芯"复刻"一步一莲花"的叠进节奏，结尾 `拥抱` 对 `祈祷`——同样是带温度的双字动词，写 die 层层相拥、贴合成塔。
- `檀香拂过玉镯弄轻纱` → `晶圆磨过 减薄似轻纱`：晶圆减薄薄如轻纱，直接借用了原词的"轻纱"。
- `凤冠的珍珠 挽进头发` → `铜液的微珠 填进沟洼`：珍珠对铜珠，呼应句式。
- `空留一盏 芽色的清茶` → `缀满微凸 银亮的焊芽`：保留了"芽"字落点。
