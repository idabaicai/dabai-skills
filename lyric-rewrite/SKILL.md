# 歌词二创与改编

帮用户把一首现成的歌改写成新主题，**套着原曲的旋律就能唱**。这是它和"随便写首诗"最大的区别：
旋律是固定的，所以改编词必须卡进原词的字数、节奏和韵脚里，否则唱起来会"多一个字""少半句"，
整首歌就垮了。你的工作就是在这个硬约束下，把新主题写得既贴合又有记忆点。

## 第一步：拆解原词，建立"骨架"

拿到原词后，先在心里（或草稿里）把它拆成可改编的骨架，这决定了改编词的所有硬约束：

- **分段**：哪几句是主歌（Verse）、副歌（Chorus / Hook）、桥段（Bridge）。副歌是记忆点，最重要。
- **逐句字数**：数出原词**每一句的汉字数**（标点不算）。这是最硬的约束——改编词每句字数要一一对应。
  例：原句"我曾经跨过山和大海"= 8 字，改编句也必须是 8 字。
- **韵脚**：原词在哪些句尾押韵、押的什么韵母（如 ang / ai / ou）。改编词要在相同位置押韵，
  押同一个韵或换一个统一的新韵都行，但不能时押时不押。
- **记忆点 / 招牌句**：副歌里最洗脑、最戳人的那句（如《海阔天空》结尾的"只你共我"、《小苹果》的
  "火火火火"）。改编这句时**尽量贴着原句的句式、节奏和情绪走**，呼应它的句式或谐音，
  让人一听就 get 到"这是改的那首歌"。这不只是为了"像"——招牌句往往是整首歌最顺口、最上头的地方，
  贴着它改，新词自然也顺口；丢开它另起炉灶（比如把深情的"只你共我"换成泛泛的"向前冲"），
  味道和顺口度就会一起垮掉。这种"原词的影子"是二创的乐趣所在，尤其 parody。

如果用户只给了主题没给原词，或原词不全，先确认是哪首歌、把原词补全再开始，**不要凭印象瞎填**。

## 第二步：按主题重新填词

带着骨架往里填新内容。把握几个要点：

- **字数严格对齐，但绝不"凑字"**：每句字数对上原词是第一优先级——但"对齐"不等于硬塞字。
  差一个字时，**整句换个说法重写**，绝不能靠掰断词语或塞废字来凑数。典型反例：把"下班"凑成
  "下一班"、"请假"凑成"请一假"、句尾硬加"啊/呀/哟"、或塞个英文词（"改 BUG"）来顶字数——
  这些唱出来一耳朵就听得出是凑的，很出戏。**字数对、而且是顺口的人话，才算真对齐。**
  能用中文表达就别夹英文，因为英文按音节算字最容易把句子搞长搞短。写完用脚本核对字数（见"自检"）。
- **主题贯穿**：新主题要从头到尾立得住，不要主歌讲 A、副歌突然跳到 B。先想清楚这首改编的
  "一句话主旨"是什么，让每一段都为它服务。
- **押韵顺口**：句尾落在韵脚上，读起来顺。避免为了押韵硬凑不通顺的词。
- **避免"倒字"（进阶）**：中文歌里字的声调最好顺着旋律走向，强拍（通常是每句开头和重音位置）
  落在意思重的字上。你不一定有谱子，但凭语感让句子的停顿和原词一致，唱起来就不别扭。
- **保留记忆点的劲儿**：副歌要比主歌更抓耳、更上口，该重复的地方跟着原词重复。

### 如果是 parody（恶搞 / 玩梗）

parody 的目标是好笑、有反差、有梗，额外注意：

- **谐音与呼应**：和原词押同样的音但换意思（"我们不一样"→"我们不一样，每个人加班都有不同的惨"），
  这种"踩着原词改"的笑点最高级。
- **反差与具体**：梗要具体、有画面感、戳中目标人群（程序员、打工人、某行业）的共同经历。
  空泛的吐槽不好笑，具体的细节才好笑。
- **保持可唱**：再搞笑也得能唱。别因为塞梗就破坏字数和节奏。

## 第三步：自检字数对齐

写完**必须**核对每句字数是否和原词对齐——这是可唱性的命门，靠肉眼数容易错。用自带脚本：

```bash
python3 scripts/check_syllables.py --original original.txt --new new.txt
```

两个文件每行一句、句子顺序一一对应。脚本会逐行报出原词字数 / 改编字数，并把**不一致的行高亮标出**。
把不齐的句子改到字数一致为止。如果某句因创意确实差 1 字，要么调整用词补齐，要么向用户说明这一处的取舍。

（脚本只数汉字、忽略标点；遇到歌词里夹英文单词时，按"一个英文单词≈按音节数折算"人工判断，脚本结果作参考。）

但**脚本通过只代表"字数对"，不代表"唱得顺"**。所以再补一步"出声读"：把每句按原曲的节奏读
（或哼）一遍，专门盯两件事——有没有为凑字憋出来的生硬词（掰断的词、多余的虚字），
以及该重读的字是不是落在了没意义的虚词上。读着别扭的句子，哪怕字数是对的，也宁可推倒重写。
字数靠脚本，顺口靠耳朵，两关都过才算成品。

## 输出格式

默认给**干净、可直接用的成品歌词**，按原曲分段并标注结构：

```
《改编歌名》（原曲：《xxx》）

[主歌]
第一句
第二句
...

[副歌]
...
```

根据用户需求追加（用户没要求就不用全给，保持干净）：

- **韵脚/节奏说明**：在歌词下方简短标注每段押的韵、字数对齐情况，方便用户微调。
- **新旧对照**：原词与改编词逐句并排，看清改了什么（用户想对比时给）。
- **多个版本**：用户要备选时，给 2–3 个不同风格或力度的版本（如"温情版 / 搞笑版 / 燃版"），
  每版都各自满足字数对齐，并一句话说明各自定位。

## 一个简短示例

原句（副歌，逐句字数 7 / 7）：
```
我们不一样　　　不一样
每个人都有不同的境遇
```
打工人 parody 版（字数对齐 7 / 7，押同韵）：
```
我们都一样　　　都一样
每个人都逃不过加班
```
注意：呼应了原词句式、押住了韵、字数卡死——这样才唱得上去。
